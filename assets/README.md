# 图标设计

深石墨背景、缎面钛金属测速弧线与指针，一点克制的青绿色。避免文字、刻度、粒子和大面积炫光，小尺寸以轮廓识别为主。

使用内置 imagegen 生成；`icon.png` 为最终原始 PNG，`dist/icon.png` 是构建时复制的分发文件。该资产随项目使用 MIT 协议。

## 最终提示词

Use case: logo-brand. Asset type: a finished square app/plugin icon for an independent open-source Loon network speed test plugin, delivered as a single 1024x1024 image, not a mockup. Primary request: understated, premium and tactile; very simple at 32px. One iconic speedometer mark: a restrained incomplete circular arc in satin silver with a single clean tapered needle pointing upper right, and a tiny muted teal highlight at the arc tip. The needle may subtly suggest a streamlined feather, but no literal bird or extra symbols. Front-on centered composition, strong silhouette, generous 20% internal breathing room. Background: an edge-to-edge deep graphite square with a very gentle dark mineral gradient. Materials: softly brushed titanium for the thick arc and needle, precise shallow bevels, subtle studio highlights and extremely soft contact shading, sophisticated matte finish. Use simple bold geometry and only a few broad surfaces. Icon fills the square; the platform will apply corner masking, so no floating tile, no external margin, no scene or perspective. No letters, no words, no numerals, no tick marks, no charts, no decorative particles, no rainbow, no neon glow, no glossy plastic, no watermark. Keep the mark clean, visually balanced and memorable.

## README 安装按钮

`add-to-loon.svg` 为项目内编写的矢量按钮：深石墨底、细金属描边、青绿指针；没有外部图片或字体依赖，浅深色背景均可使用。按钮图片仅负责外观，README 外层链接使用官方 HTTPS 通用导入地址，并对完整 Raw 插件 URL 编码。该 SVG 同样采用 MIT 协议。
