# Loon 真机回归

兼容目标 Loon ≥3.2.1 (745)。以下真机项目需要用户协作，当前均待验证；开发环境的 Node/VM 与本地回环验证单独见 VERIFICATION.md。记录设备、iOS、Loon 完整版本、插件版本/提交、网络与节点。

- [ ] 分别在 3.2.1（745）及当前版安装插件；控件显示正确，修改模式/并发/预算后立即运行能读到新值，日志包含实际 Loon 版本。
- [ ] 自定义 URL 含多个查询参数、加号、百分号、逗号，以及含标点节点名时，连接记录与输入一致。
- [ ] README 首屏的图标居中，版本/构建/MIT/Loon 徽标可见；点按钮可导入，Raw 地址可手动添加。
- [ ] 更新插件及脚本缓存；入口名为「节点速度测试」，日志显示 v0.5.1，参数出现独立的下载源与上传源；旧下载参数若是 CF 手动改为 Apple CDN。
- [ ] 从节点菜单运行时，匹配目标的 name/type 显示为协议 · AnyTLS、Hysteria2、Trojan、Shadowsocks 等；AnyTLS 只在支持此协议的 Loon 版本验证，与节点列表对照。
- [ ] 手填其他节点、策略组或未提供协议信息时显示“协议 · 未知”，DIRECT 显示直连，不套用入口协议。
- [ ] 未知原因码仅在日志中，通知和弹窗不增加诊断行，不记录完整 nodeInfo；配置 A、入口 B 时实际请求仍走 A，冲突提示只出现一行，入口与配置一致时不出现。
- [ ] 填 node，默认 both / single；结果同时显示下载和上传 Mbps、各自来源；没有白色文字背景块、过大数字或长篇说明。
- [ ] 浅/深色、长节点名、compare 四项与部分成功/错误状态均可读。
- [ ] 并发 2 → 1、4 → 2、双向仅一项降载及 compare 均保留所选模式与各项实际请求并发；失败恢复不显示为成功。
- [ ] 节点菜单为黑白系统上下行箭头，没有黑色方块；插件列表品牌图标为透明底。
- [ ] 连接记录确认 GET 与 POST 都走指定节点；DIRECT 对照；未指定目标时不发请求。
- [ ] direction=download / upload 可单独运行；single / concurrent（2/4/8）/ compare 各自正确。
- [ ] compare 顺序为单路下载、并发下载、单路上传、并发上传，不重叠；每轮分别预热。
- [ ] Apple 下载普通 HEAD 200（包含缺少 Accept-Ranges）能通过，GET 206 校验正确；默认上传也走 Apple `/slurp`，返回 200 且 Bytes 与请求体相等；两项分别标注源。
- [ ] 分别切换下载/上传源；预设只忽略对应自定义字段。自定义下载支持 Range，自定义上传须填写 URL，完整接收 POST 后返回 200/204。
- [ ] 总预算包含全部方向/模式和预热；双向 compare 64 MB 时四项各 16 MB。预热不计正式速度。
- [ ] 达时长停止新请求并收尾；快速耗尽预算有短样本提示。核对实际消耗，不能把预算当计费上限。
- [ ] 下载失败、上传失败各自复测；成功项仍保留，失败项为“—”，不假装 0 Mbps；失联请求不进入下一项。
- [ ] 断网、超时、限流、不支持源、通知开关、本地存储及连续三次资源占用正常。
- [ ] 成功通知只显示一行「节点速度测试」标题，无重复副标题，正文从节点信息开始；部分完成、未完成及启动失败仅用简短副标题提示状态，具体错误仍可见；关闭通知后结果弹窗正常。

反馈附参数、版本、连接记录和日志；可隐去节点名。桌面原生 HTML 预览与 Mac 网络冒烟不替代以上真机验收。

- [ ] CF 上传对端关闭时弹窗显示短中文原因，完整错误保留日志；旧配置超时为 5 秒时调到 10–15 秒复测。
- [ ] 英文节点名与来源使用无衬线，预热失败不只显示“未完成”。

- [ ] 更新后确认 adaptive=true、httpVersion=auto；旧 chunkKB 视为下载上限，上传独立 uploadChunkKB。
- [ ] 两份原日志对应节点重测：预热为单路 64 KB 起步；如仍失败，附每笔耗时、状态和 requestTimeout。
- [ ] 分别固定 h2/h1 测 Apple 下载/上传，核对连接记录及节点路由；不改全局模式。
- [ ] 明确瞬时失败最多一次恢复，恢复前无在途，结果实际并发与日志一致；403/429、范围/回执错误不重试。
- [ ] 证书、DNS 和未知错误不重试，也不因包含 timeout/reset 字样降级到 H1；不得为验证此项关闭证书校验。无法安全构造的真机场景保留待验证，并引用对应自动化证据。
- [ ] 未回调显示已确认数据与未回调数量，停止上传/下一轮，不出现假成功。
- [ ] CF 网页对照使用相同设备、网络、节点和 CF 源，记录网页数值与出口；不同源不直接比较。

## H1/H2 对照记录

固定设备、网络、节点、测速源、方向、预算、预热和分块上限，分别运行下表。每项记录实际 Loon/iOS 版本、提交、结果、请求的 HTTP 配置、实际在途数、是否尝试恢复和最终是否成功；只在连接记录确实提供证据时记录协商协议/连接数，否则填写「不可观测」。单次结果不能外推所有节点，H1 配置也不等于独立 TCP 连接保证。

| HTTP 配置 | 模式 | 自动化覆盖 | Loon 真机结果 |
| --- | --- | --- | --- |
| h1 | single | 调度与统计有模拟覆盖 | 待验证 |
| h1 | concurrent | 调度与统计有模拟覆盖 | 待验证 |
| h1 | compare | 顺序与预算有模拟覆盖 | 待验证 |
| h2 | single | 配置透传有模拟覆盖 | 待验证 |
| h2 | concurrent | 配置透传有模拟覆盖 | 待验证 |
| h2 | compare | 配置与比较条件有模拟覆盖 | 待验证 |

auto 模式另核对有限 H1 回退。这里的模拟覆盖只确认程序行为，不确认 Loon 底层连接复用；真实记录可以在 [#5](https://github.com/fanbuz/loon-speedtest-plugin/issues/5) 中补充。
