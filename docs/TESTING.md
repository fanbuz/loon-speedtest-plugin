# Loon 真机试用清单

当前均待真机执行。记录设备、iOS、Loon 完整版本、网络类型、目标节点/策略组；分享日志前可删去节点名。

## 安装与基础运行

- [ ] GitHub Raw 的插件、JS 和图标均可获取；Loon ≥ 3.5.1 (983)，能看到参数和 Generic 手动入口。
- [ ] node 填精确节点名；mode=single、duration=5、maxMB=16，运行后HTML 结果页出现非空的数据量、耗时和速度摘要。
- [ ] 在 Loon 连接记录确认每条测速请求经过该节点；另用 DIRECT 对照，排除实际走错路由。
- [ ] node 留空且无上下文时显示明确错误，没有发下载请求。
- [ ] 从节点/策略组入口传参时正确获取名称；若仅有 nodeInfo，提示填写 node 而不是静默走直连。

## 测速源

- [ ] 不改测速源时走 Cloudflare，填写任意 test_url 不影响预设源。
- [ ] 选 Apple CDN，先完成普通 HEAD 范围能力声明检查（200 正常），再按 Range 下载，不请求完整 4 GB 文件。
- [ ] 选自定义且 test_url 为空时给出错误，不发下载请求。
- [ ] 自定义有效直链使用原始 URL 和查询参数，HEAD 声明 bytes 且 GET 206/Content-Range 校验通过。
- [ ] 自定义源不支持分段时明确失败，不退回整文件下载；重新选预设源后忽略 test_url。

## 单路、并发和对比

- [ ] 同一节点、同一网络、同源分别跑 single / concurrent，默认并发数 4；由连接记录和日志确认在途请求上限。
- [ ] compare 先单路再 4 路，第一轮排空后才开始第二轮；64 MB 总预算每轮 32 MB。
- [ ] 换 2 路、8 路及分块 250 KB / 4000 KB，检查运行稳定性。最高配置不是所有设备的推荐值。
- [ ] 达到发请求时长后不新增请求；等待在途请求结束，最终耗时允许大于 duration。
- [ ] 快速链路提前耗尽小预算时给出短样本提示；日志未将回调完成量显示成真实瞬时速度。

## 预热与统计

- [ ] 默认先预热，再开始正式计时；预热数据和时间不计入平均速度。
- [ ] 预热仍计入总数据预算，最多占每轮 1/4；两个阶段排空后才衔接。
- [ ] compare 每一轮都独立预热；warmup=0 时关闭预热。
- [ ] 页面区分正式数据、测量耗时、预热、总已确认数据与在途收尾；Mbps/MB/s 换算自洽。
- [ ] 浅色/深色、长节点名、单路/对比/失败页均可阅读，没有横向溢出。

## 失败与输出

- [ ] 测试中断网/失效节点，能正常结束，不重试、不继续下一轮、不显示零速或虚构正常速度。
- [ ] 观察请求超时是否确实回调；缺失回调时兜底结束并标不完整，不追加比较轮次。
- [ ] 通知开启与关闭分别有效；系统拒绝通知时日志和HTML 结果页仍有结果。
- [ ] 最后结果能保存，且没有改全局运行模式或策略选择。
- [ ] 连续执行 3 次观察波动和资源占用；记录实际消耗，不把请求数据预算当计费流量上限。
