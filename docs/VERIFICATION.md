## 数据核对

用户截图为正式数据 18.00 MB、显示耗时 10.38 秒、1.73 MB/s、13.88 Mbps。18 / 10.38 ≈ 1.734 MB/s ≈ 13.873 Mbps；在原始耗时 10.376 秒时，各字段分别舍入会得到截图的完整显示值。截图数值没有明显换算错误，但只能表示分块应用层平均速度，不能证明线路峰值或节点路由。

已用模拟调度器复现 18 MB / 10.376 秒，覆盖真实字节计数、平均公式及单位换算。新版结果页以 Mbps 为主，MB/s 保留三位小数，避免先舍入后换算。

## 自动化

`npm run check`：49 项通过，临时构建与生成 JS 语法检查通过。包括：

- 原有参数、路由、并发、预算、时长、异常、限流和真实二进制长度校验。

- HTML 结果输出、通知关闭、错误状态、动态内容转义、无外部资源依赖。
- 默认 Raw 地址、版本查询参数、其他托管和本地构建，非法参数不覆盖已有发行包。

## 真实接口与完整流程

| 检查 | 结果 |
| --- | --- |
| Apple 普通 HEAD | HTTP 200，Accept-Ranges: bytes，Content-Length: 4294967296 |
| Apple GET Range 64 KB | HTTP 206，Content-Range: bytes 0-65535/4294967296，实读 65536 B |
| Apple 完整预热 + 测量 | 两轮各预热 0.50 MB、正式 1.50 MB，合计 4 MB，正常结束 |
| CF 完整预热 + 测量 | 单路预热 0.50 MB / 正式 0.75 MB，并发预热 0.50 MB / 正式 1.50 MB，按窗口或预算正常结束 |
| 自定义本地 Range 流程 | HEAD 200 + GET 206；每轮预热 0.50 MB / 正式 1.50 MB，合计 4 MB，正常结束 |

以上使用 Node HTTP 客户端访问 Mac 系统网络或本地回环。工具中的 DIRECT 是标签，不是已验证的 Loon 路由；接口与流程成功不代表手机节点带宽已验收。
