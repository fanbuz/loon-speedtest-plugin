# v0.1.1 需求

状态：第一版代码可试用，Loon 真机验收待完成。

## 目标

用户能在 Loon 中手动比较一个指定节点或策略组的单路下载与多路并发下载表现。使用结果弹窗、日志和可选系统通知显示可解释的结果，不要求复刻截图原生 UI。

用户确认「单测」指单路下载，与多路并发相比较；自动化单元测试是开发验证手段，属于另一件事。

## 范围

| 工作包 | 当前交付 |
| --- | --- |
| 运行入口 | Generic 手动脚本；不配置定时或网络变化自动测速 |
| 测速源 | 默认 Cloudflare；下拉可选 Apple CDN 或自定义；test_url 仅自定义生效 |
| 下载模式 | single、concurrent、compare；并发默认 4 |
| 路由 | 所有请求显式 node；无有效目标则报错 |
| 停止条件 | 时长 / 请求数据预算先到先停发；排空在途请求 |
| 结果 | 结果弹窗、平均 MB/s、Mbps、有效数据量、耗时、停止原因、错误、样本 |
| 工程验证 | 参数、数学口径、调度、异常、Loon API 适配自动化测试 |
| 安装 | 构建独立脚本与插件；GitHub Raw 默认分发；可指定其他托管或本地文件服务 |

## 非目标

批量遍历全部节点、定时跑分、自动切换全局策略、上传测速、TCP/UDP 中继延迟、丢包、精确瞬时速率、峰值/中位数、独立 TCP 连接保证、远程托管发布。

## 成功标准

在支持新语法的 Loon 上安装插件，明确设置目标后能分别完成单路与并发测试；连接记录证明目标路由正确；对比模式阶段不重叠；低预算和断网时能退出且不显示伪造速度。完整核对见 [真机测试](TESTING.md)。
