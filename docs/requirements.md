# 节点速度测试 v0.3.1

在 Loon 中测试同一节点的下载与上传速度。默认双向，依次下载、上传；可只测一个方向。每个方向支持单路、2–8 路并发及单路/并发顺序对比，分别预热和计时。

下载与上传分别下拉选择 Apple CDN、Cloudflare、自定义，默认均为 Apple CDN。只有对应方向选自定义时，test_url / upload_url 才生效且需填写有效地址。Apple 上传需校验服务端 Bytes 与发送请求体相同。

界面使用适合 Loon 原生弹窗的紧凑富文本，显示节点、节点协议、下载/上传 Mbps、来源、模式与总耗时/数据量。详细预热、正式统计、异常和预算信息保留在日志及本地结构化结果中。失败不显示假速度，部分成功保留成功项。

README 首屏居中显示图标、名称、徽标和一键导入按钮。只保留安装、使用、必要选项和开发入口；不包含图标生成过程。

GitHub Raw 分发；MIT。批量节点、自动切换策略、定时运行、UDP/丢包及真实逐秒速率不在本次范围。

Apple/自定义的 HEAD 200 缺少范围能力声明不得误判为不支持；仍须由实际 GET 206、Content-Range 和真实长度验证。预热失败需直接显示具体原因，默认请求超时 10 秒。

节点菜单使用 Loon 的系统上下行箭头图标，与其他原生入口协调；品牌图标保留金属符号并改透明背景，用于插件列表与 README。

节点协议读取 Loon 入口提供且与实际测速目标匹配的 nodeInfo.name/type，结果在节点名称下展示。DIRECT 标直连，未知或不匹配不猜测；不记录完整节点信息。
